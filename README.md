## ✨ About

**Ghosts** adds friendly spectral companions, tiny seedling spirits, Kodamas, haunted trees, spooky wood blocks, and a soft little forest-magic mood to Minecraft.

This repository keeps a small compatibility port for newer Minecraft/Fabric versions, while trying to stay close to the original mod behavior.

## 📦 Requirements

- **Minecraft:** `26.1.2`
- **Java:** `25` or newer
- **Fabric Loader:** `0.19.2` or newer
- **Fabric API:** `0.149.0+26.1.2` or newer
- **GeckoLib:** `5.5.1` or newer

## 🛠️ Build

```bash
sh ./gradlew build --console=plain
```

The built jars are generated in:

```text
build/libs/
```

## 🧪 Status

**Experimental port.** It has been tested locally for startup, resource loading, item/block textures, selected recipes, entity spawning, ghost interactions, Kodama behavior, Small Ghost behavior, and selected survival mechanics.

Please treat early releases gently and report crashes, missing textures, or behavior differences with logs and reproduction steps.
